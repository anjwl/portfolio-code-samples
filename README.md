개발 환경: Unity 6 / C#	<br>
개발 인원: 4명 (기획 1, 아트 1, 프로그래밍 2) <br>
개발 기간: 2025.07 ~ 2026.08

### 에디터의 오브젝트, 타일 데이터 분리
[코드](./UnDo/UserEditor.cs)

## Rhythm Game Maker
인게임 에디터로 채보를 제작하고 즉시 플레이할 수 있는 노트 낙하형 리듬 게임

개발 환경: Python / Pygame <br>
개발 인원: 1명 <br>
개발 기간: 2021.11 ~ 2023.04

### 입력과 렌더링 주기 분리
[코드](./Rhythm%20Game%20Maker/public_main.py)

기존에는 입력 처리와 렌더링이 하나로 묶여 있어 입력이 목표 FPS에 맞춰서 처리됐습니다. <br>
이는 리듬게임에서 큰 악영향을 주는 불규칙적인 입력 딜레이를 만들었습니다. <br>
이를 수정하기 위해 입력과 게임 로직은 매 반복마다 처리하고 렌더링만 목표 FPS에 맞춰 실행하도록 주기를 분리했습니다.

| 구조 | 평균 입력 오차 | 표준편차 | CPU 비율 |
|---|---|---|---|
| 렌더링 루프에서 입력 처리 | 13.25ms | 8.94ms | 약 70.0% |
| 입력과 렌더링 주기 분리, 대기 없음 | 1.55ms | 2.33ms | 약 96.9% |
| 입력과 렌더링 주기 분리, 0.5ms 대기 | 3.88ms | 3.84ms | 약 68.7% |

추가로 CPU 비율을 고려하여 0.5ms의 짧은 대기 시간을 추가해 CPU 사용을 크게 늘리지 않도록 했습니다.
